# One Stop Cabinets · Interactive kitchen concept

The complete Next.js application is in [`prototype/`](prototype/).

**[Open the public demonstration](https://one-stop-kitchen-concept-ali.quietcrab12.chatgpt.site)** · [Start the five-minute walkthrough](https://one-stop-kitchen-concept-ali.quietcrab12.chatgpt.site/demo/)

```bash
nvm use
npm ci
npm run dev
```

**Vercel ready:** import this repository with Root Directory `.`. The checked-in configuration builds `prototype/` and publishes `prototype/out`. No environment variables are needed. See [Vercel deployment instructions](VERCEL_DEPLOYMENT.md).

Read the [application README](prototype/README.md), [five-minute demo guide](prototype/DEMO_GUIDE.md), and [future integrations](prototype/FUTURE_INTEGRATIONS.md).

Independent sales demonstration. All customer records are fictional. Enquiries, chat and project changes remain in the visitor's browser; nothing is sent to One Stop Cabinets or FAMS Renovations.
